串接 Google Sheets 說明

如欲讓學生填寫後直接寫入 Google 試算表，請按照以下步驟操作：

  1. 開啟您的 Google Sheet 試算表，點選選單「擴充功能」>「Apps Script」。
  2. 貼上以下程式碼並存檔：
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    new Date(),
    data.studentId,
    data.name,
    data.badminton,
    data.basketball,
    data.selectedRatio,
    data.finalScore,
    data.reflection
  ]);
  return ContentService.createTextOutput("Success");
}
  1. 點選右上角「部署」>「瞭解新部署」，選擇類型為「Web 應用程式」。
  2. 將「誰有權存取」設定為「任何人 (Anyone)」，並完成部署。
  3. 複製取得的 Webhook 網址即可進行串接。
